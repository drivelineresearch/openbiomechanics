# Third-party tools

The Mokka 0.6.2 C3D viewer installers previously stored here have been moved to a
GitHub Release to keep the repository lightweight. They are preserved because the
upstream download is not always available.

- **Download:** [`tools-mokka-0.6.2`](https://github.com/drivelineresearch/openbiomechanics/releases/tag/tools-mokka-0.6.2)
  (or run `scripts/download_data.sh --skip-data --with-mokka`)
- **Upstream project:** Mokka is developed by the [Biomechanical ToolKit](https://biomechanical-toolkit.github.io/mokka/).

Mokka lets you open and visualize the `.c3d` files from the `dataset-v1` release.
